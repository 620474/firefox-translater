# AI Article Reader для EinkBro

Используйте версию EinkBro с поддержкой Userscripts и API `GM_getValue`,
`GM_setValue`, `GM_listValues`, `GM_deleteValue`, `GM_xmlhttpRequest`,
`GM_registerMenuCommand`. Старый механизм Post-load JavaScript для этого пакета
не подходит. Реализация проверяется по актуальному коду EinkBro; точную совместимость
с установленной у вас версией необходимо проверить на устройстве.

1. Скачайте `ai-article-reader-einkbro-vX.Y.Z.user.js` из релиза.
2. В менеджере пользовательских скриптов EinkBro импортируйте файл и включите его.
3. Откройте статью и обновите страницу. Появится кнопка «文A».
4. Долгое нажатие → «Настройки AI и моделей». Выберите провайдера, сохраните API-ключ
   и модель. Настройки также доступны через команду скрипта в меню EinkBro.
5. Короткое нажатие переводит статью; меню содержит оригинал, саммари, действия
   с выделением и заметки. Режим E-Ink включается по умолчанию.

Пакет использует те же `background.js`, `content.js`, `reader-core.js`,
`reader-actions.js`, `floating.js`, настройки и заметки, что и Firefox.
Адаптер заменяет WebExtension API на GM API. Сборка автономна: внешних JS-зависимостей
и загрузки исполняемого кода с серверов нет.

Ключи, заметки и кэш хранятся в хранилище userscript, а не в localStorage сайта.
Это не обеспечивает изоляцию уровня расширения Firefox: EinkBro выполняет скрипты
в окружении веб-страницы. Используйте на доверенных сайтах и отдельный API-ключ
с ограничением расходов. Разрешение `@connect *` требуется для пользовательского
HTTPS gateway; по умолчанию запросы идут только выбранному AI-провайдеру.
Не экспортируйте userscript-хранилище вместе с ключами.

Ограничение: несколько вкладок имеют собственные очереди обновления хранилища;
не сохраняйте заметки и настройки одновременно в разных вкладках.
