# AI Article Reader

Три отдельных пакета с общей версией релиза. EinkBro — основная платформа.

| Платформа | Пакет | Установка |
|---|---|---|
| EinkBro | `ai-article-reader-einkbro-vX.Y.Z.user.js` | Импорт в менеджере Userscripts |
| Firefox Android / ПК | Подписанный `.xpi` | Установка дополнения Firefox |
| KOReader | `ai-article-reader-koreader-vX.Y.Z.koplugin.zip` | Распаковать в каталог `plugins`, перезапустить |

Инструкции: [EinkBro](platforms/einkbro/README.md), [KOReader](platforms/koreader/README.md).
EinkBro требует актуального механизма GM userscripts: вставка файла в Post-load JS не подходит.
EinkBro и Firefox поддерживают перевод веб-страницы, оригинал, саммари, действия над выделением
и заметки. KOReader работает с выделением книги: перевод, объяснение, термин, тезисы, свой
промпт, заметки. Он не подменяет текст всей книги. Первые версии новых клиентов требуют
проверки на устройствах; автоматические проверки используют DOM и имитацию платформенных API.

Общие браузерные исходники собираются в EinkBro автоматически. Промпты пяти действий
генерируются для KOReader из `reader-actions.js`. NestJS gateway общий и необязательный
для всех трёх платформ; прямые запросы к Gemini, DeepSeek и OpenAI доступны в каждом клиенте.

Все пакеты: `npm run package:all -- 1.4.0`. Только EinkBro и KOReader:
`npm run package:platforms -- 1.4.0`. ZIP Firefox содержит исходники; установочный XPI
создаётся в CI при настроенных ключах Mozilla. Сборка не требует системной команды `zip`.

## Firefox

Расширение Firefox для Android и ПК: AI-перевод статей на русский, подмена оригинального текста, суммаризация. Поддерживает Medium через обычную авторизованную сессию и другие веб-страницы.

## Возможности

- Собственные ключи Gemini, DeepSeek и OpenAI; выбор модели из API или ручной ввод ID.
- Перевод текстовых узлов без разрушения HTML-разметки и блоков кода, восстановление оригинала, локальный кэш.
- Суммаризация в трёх форматах, длинные статьи обрабатываются частями.
- Контрастный интерфейс для Android / E-Ink.
- Прямые запросы к AI-провайдеру **без сервера** (по умолчанию) либо необязательный NestJS gateway.

## Структура

- manifest.json, background.js, content.js, popup.* — Firefox WebExtension (Manifest V2).
- apps/api — NestJS 11 API gateway, который **не запускается внутри Firefox**.
- scripts/ — упаковка расширения и опциональная подпись Mozilla.
- platforms/einkbro — адаптер GM API и инструкция установки userscript.
- platforms/koreader — Lua-плагин, транспорт AI и инструкция установки.
- .github/workflows/release.yml — GitHub Actions + semantic-release.

## Разработка

Node.js 22+:

    npm install
    npm run check
    npm run build:api

На desktop Firefox: about:debugging → This Firefox → Load Temporary Add-on → manifest.json.

На Android обычная установка требует **подписанного Mozilla .xpi**. Неподписанный ZIP из GitHub Releases служит исходным архивом и не заменяет подпись.

### Подключение AI

В панели укажите провайдера, API-ключ и модель, сохраните настройки, откройте Medium в авторизованной вкладке и нажмите Перевести или Сделать саммари. Подписка ChatGPT Plus не включает OpenAI API. Бесплатные квоты Gemini API зависят от проекта и модели.

### Необязательный NestJS сервер

    npm install
    npm run build:api
    PORT=3000 npm run start:api

Маршруты: GET /api/health, GET /api/models?provider=gemini, POST /api/generate.

Ключ передаётся заголовком X-Provider-Api-Key при каждом запросе, сервер его не сохраняет. Для доступа с телефона/читалки используйте HTTPS и reverse proxy. В настройках расширения выберите режим NestJS и укажите URL. HTTP разрешён только для localhost.

CORS_ORIGINS — необязательный список разрешённых origins через запятую. Для публичного VPS дополнительно рекомендуются rate limiting и авторизация на gateway.

## Автоматические релизы

На каждый push в main GitHub Actions запускает тесты, компилирует NestJS, затем semantic-release. Conventional Commits:

- fix: ... — patch
- feat: ... — minor
- feat!: ... или BREAKING CHANGE: — major
- docs: / chore: без функциональных изменений не создают релиз

При успешной сборке публикуются GitHub Release, git-тег vX.Y.Z, release notes, userscript EinkBro,
архив плагина KOReader и ZIP с исходниками Firefox. При настроенной подписи Mozilla также
публикуется XPI. npm publish выключен.

Для **подписанного XPI** настройте addons.mozilla.org API credentials в GitHub Actions Secrets:
- AMO_JWT_ISSUER
- AMO_JWT_SECRET

Тогда команда web-ext sign --channel=unlisted запросит подпись Mozilla, и подписанный XPI прикрепится к GitHub Release. Без secrets автоматически выходит только ZIP.

Локальная упаковка:

    npm run package:extension

Результат в dist/extension и dist/firefox-translator-v0.1.0.zip.

## Плавающая кнопка (Android и E-Ink)

После установки расширения откройте статью (например, Medium) и обновите вкладку, чтобы content script появился.

- **Один тап** по полупрозрачной кнопке «文A» → перевод на русский с подменой текста.
- **Долгое нажатие (около 0,5 с)** → меню: перевести, вернуть оригинал, суммаризация, настройки модели и API-ключа.
- **Перетаскивание** → перенос кнопки к левой или правой кромке; положение запоминается.
- **Прозрачность** настраивается от 12 до 95 %, по умолчанию 28 %.
- **Режим E-Ink** убирает анимацию и тени, оставляет чёрно-белый контраст.

Кнопка добавлена поверх страницы без изменения её структуры. Настройки API открываются в отдельной вкладке расширения; секреты не передаются в DOM сайта. Если кнопка не появилась после обновления, убедитесь, что расширение включено и Firefox дал ему доступ к сайту.

## Безопасность

- Ключи сохраняются в browser.storage.local и не вставляются в HTML страницы, но это не зашифрованный сейф.
- Тексты статей отправляются **выбранному AI-провайдеру**; не переводите конфиденциальные страницы.
- Расширение запрашивает доступ к HTTP(S) сайтам, чтобы работать на разных статьях.
- Списки API-моделей могут содержать несовместимые с Chat Completions модели; вручную переключитесь на подходящую.
- Кэш не синхронизируется между устройствами.

## Согласие на передачу данных Mozilla

Начиная с новых версий расширение декларирует обязательные типы данных
`websiteContent` (текст обрабатываемой статьи) и `authenticationInfo`
(API-ключ выбранного AI-провайдера). Это не означает, что разработчик собирает
данные: они передаются провайдеру или на сервер пользователя, если включён режим
NestJS. Подробнее: [PRIVACY.md](PRIVACY.md).

Для встроенного согласия Mozilla минимальная версия Firefox составляет 140 на ПК
и 142 на Android. На более старых версиях расширение этой версии не установится.

## Улучшенный перевод (движок v2)

- Переводит **целые смысловые абзацы**, а не отдельные текстовые ноды. Встроенные
  элементы (ссылки, выделение жирным, курсив) кодируются парными маркерами и
  возвращаются как безопасные DOM-элементы, а не через AI-generated innerHTML.
- HTML оригинальной статьи остаётся в DOM нетронутым; он скрывается, пока его
  переведённый соседний элемент отображается на странице. Повторный тап переводит
  новые / изменившиеся фрагменты, «Оригинал» удаляет переведённые копии.
- Перевод начинается с **видимой области**. Запросы идут пакетами, не больше двух
  параллельно; прогресс отображается на плавающей кнопке.
- Gemini использует JSON MIME, DeepSeek / OpenAI — JSON Object при поддержке
  выбранной моделью. Ответы валидируются: все IDs и встроенные маркеры должны
  присутствовать, иначе повреждённый перевод не применяется.
- API-запросы повторяются для 429 и временных ошибок. Саммари открывается в
  контрастном изолированном окне, режим E-Ink отключает тени.
- Кэш: максимум **250 записей**, **2,5 МБ** и **30 дней**. Очистка доступна в
  настройках. Кэш версии v2 не использует старые записи, которые можно удалить
  через «Очистить кэш переводов».

**Известные ограничения:** при обновлении DOM динамическим сайтом переведённый
абзац может быть сброшен на оригинал: нажмите перевод ещё раз. Простой
селектор смысловых блоков может пропускать вводный текст у многоуровневых
списков. Не все модели поддерживают Chat Completions или JSON Object. В случае
ошибки выберите совместимую модель. Проверки в CI используют эмуляцию DOM —
проверка на реальном Firefox Android и Hanvon остаётся необходимой.



## Действия над выделенным текстом (вдохновлено KOReader)

Выделите текст внутри статьи и удерживайте плавающую кнопку ~0,5 сек.
В меню появятся **Перевести фрагмент**, **Объяснить**, **Термин**,
**Тезисы** и **Мой промпт**. Для каждого действия в запрос добавляется
контекст соседнего абзаца и название статьи. Промпт редактируется в настройках
и сохраняется только в локальном хранилище браузера.

**Программный код не переводится.** Блоки с примерами в \`pre\`, а также
\`code\`, \`kbd\` и \`samp\` остаются в оригинале. При переводе страницы
их содержимое вообще не включается в запрос к AI: передаются только маркеры
их расположения. Можно отдельно выделить код и попросить AI **объяснить** его,
но команда «Перевести» для выделенного кода отклоняется.

После ответа можно нажать «Копировать» или «В заметки». Заметки
хранятся только в \`browser.storage.local\` (до 80 записей) и открываются
из меню плавающей кнопки или настроек. Это не синхронизация с KOReader
и не передача данных разработчику. На Android управление крупными кнопками;
окно результата на E-Ink без теней.

Идеи действий с выделениями и редактирования промптов изучены по
[KOAssistant](https://github.com/zeeyado/koassistant.koplugin) и
[Assistant.koplugin](https://github.com/liam-simmons/assistant.koplugin).
Исходный код этих GPL-3.0-проектов не копировался.
