# Firefox Translator

Расширение Firefox для Android и ПК: AI-перевод статьи прямо в DOM и суммаризация по оригинальному тексту. Подходит для чтения Medium в авторизованной сессии и других обычных веб-страниц.

## Возможности

- **Google Gemini, DeepSeek, OpenAI** — собственный API-ключ для каждого провайдера.
- **Список моделей из API** и ручной ввод ID, если новая модель ещё не появилась в списке.
- **Перевод абзацев на русский** с сохранением HTML, ссылок и блоков кода; возвращение к оригиналу.
- **Суммаризация** в трёх форматах, с обработкой длинных статей частями.
- **Локальное кэширование** переводов и саммари; очистка кэша.
- **E-Ink**: крупные элементы управления, контрастный интерфейс, без анимаций.
- API-ключи хранятся локально средствами расширения и не внедряются в DOM сайта. Никакой собственный сервер не требуется.

## Установка

В этом репозитории — готовые исходники WebExtension без шага сборки. Для установки в обычный Firefox нужно **подписать XPI через Mozilla Add-ons**. На Android расширения поддерживаются, но способ установки неподписанной версии зависит от сборки Firefox.

Для упаковки: положите `manifest.json`, `background.js`, `content.js`, `popup.html`, `popup.css`, `popup.js` в корень ZIP (не в папку внутри ZIP). Не кладите ключи или данные аккаунта в архив.

На десктопном Firefox можно временно запустить расширение через `about:debugging` → This Firefox → Load Temporary Add-on, выбрав `manifest.json`.

## Использование

1. Откройте всплывающую панель расширения.
2. Выберите Gemini / DeepSeek / OpenAI, вставьте **API-ключ именно этого провайдера**.
3. Нажмите «Получить модели», выберите модель или введите её ID вручную и сохраните настройки.
4. Откройте статью Medium, войдите в свой аккаунт и нажмите «Перевести» или «Саммари».
5. В блоке на странице можно вернуть оригинальный текст и скрыть панель.

### API-адреса

- Gemini: `https://generativelanguage.googleapis.com/v1beta/models` и `...:generateContent`
- DeepSeek: `https://api.deepseek.com/models` и `/chat/completions`
- OpenAI: `https://api.openai.com/v1/models` и `/responses`

Списки моделей показывают модели, доступные по ключу, но не гарантируют поддержку конкретного API и оплаченного тарифа. При ошибке модели попробуйте другой ID.

## Безопасность и ограничения

- Ключи сохраняются в `browser.storage.local`; хранилище **не является шифрованным сейфом**. Не импортируйте его в сторонние профили, не делитесь профилем Firefox и никогда не отправляйте ключи в репозиторий.
- Для чтения страниц расширение запрашивает доступ к HTTP(S) сайтам; тексты переводимых статей уходят напрямую **выбранному AI-провайдеру**. Не переводите конфиденциальные страницы без необходимости.
- Подписка ChatGPT Plus **не включает** API OpenAI. Аналогично, доступность бесплатных квот Gemini зависит от проекта и модели.
- Модель может неточно перевести встроенные ссылки/разметку или ошибиться в саммари; блоки кода не изменяются.
- Автоматической синхронизации кэша между устройствами нет. Перевод подписной статьи выполняется в вашей авторизованной вкладке, без обхода платного доступа.

## Разработка

MVP написан на нативном JavaScript без сборщика — удобно исправлять и тестировать прямо в браузере. Следующие этапы: ограничение разрешений по запросу, пакетные тесты, сохранение статей как EPUB и синхронизация между устройствами.
