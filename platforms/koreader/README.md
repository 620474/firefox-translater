# AI Article Reader для KOReader

Распакуйте архив так, чтобы `aiarticlereader.koplugin/main.lua` оказался внутри
каталога `plugins` KOReader, затем перезапустите KOReader.

В меню «Другие инструменты → AI Article Reader → Настройки AI» выберите провайдера,
введите ключ и ID модели. Примеры: Gemini `gemini-2.5-flash`, DeepSeek `deepseek-chat`,
OpenAI `gpt-4.1-mini`. Поле NestJS можно оставить пустым: сервер необязателен.

Откройте книгу, выделите текст, нажмите AI Article Reader и выберите действие:
перевод, объяснение, термин, тезисы или свой промпт. Отправка требует подтверждения.
Результат показывается отдельным окном; его можно сохранить в локальные заметки
или скопировать при наличии системного буфера обмена. Сетевое ожидание можно отменить.

Эта версия работает с выделением в книгах; подмена текста всей книги не выполняется.
Лимит выделения — 8000 байт UTF-8. У выделения нет HTML-разметки: распознавание кода
эвристическое. Очевидный код в режиме перевода блокируется; для кода выбирайте объяснение.
Соседний контекст книги автоматически не передаётся.

Ключ хранится в локальных настройках KOReader открытым текстом. Выделение и название
файла книги отправляются выбранному провайдеру или указанному вами HTTPS gateway.
Заметки хранятся локально (не более 80). Проверка на реальном устройстве требуется.
